# Data: what is in this repository, and how to get the rest

The core harness, its tests and the E1/E1b experiments need **no external data**: they run on a synthetic
subscription company generated by `dsh world` (`src/dsharness/world/`).

The real-data experiments use four public datasets. **None of them is redistributed here.** The repository keeps
only small derived files (aggregates, schema metadata, question banks and answer keys written by the
experimenters). Raw files go to `workspace/external/` (git-ignored); `scripts/fetch_public_data.py` downloads them
and checks them against the sha256 sums recorded when the experiments ran (`scripts/checksums/`).

| dataset | used by | publisher and terms | fetch |
|---|---|---|---|
| UCI Online Retail II (2009-12 to 2011-12, 1,067,371 lines) | E3a, E3b, E4, `examples/online_retail` | Daqing Chen, UCI Machine Learning Repository, <https://archive.ics.uci.edu/dataset/502/online+retail+ii>. **CC BY 4.0** (attribution required; the experiments shift dates and rename columns, see `experiments/E3a/build_world.py`) | `uv run --group external python scripts/fetch_public_data.py retail` |
| NYC TLC Trip Record Data, yellow and green taxi (15 monthly parquet files, about 0.6 GB) | E3d | NYC Taxi & Limousine Commission, <https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page>. NYC Open Data Law (NYC Admin. Code §23-502(d)): no licence requirement or use restrictions; republishers should name the source and describe changes. TLC states that the trip data was not created by the TLC and makes no representation of its accuracy. | `uv run python scripts/fetch_public_data.py tlc` |
| NYC TLC Industry Indicators (monthly trips and farebox per day) | E3d (independent control totals) | NYC Open Data dataset `v6kb-cqej`, attribution "Taxi and Limousine Commission (TLC)"; same terms as above. Updated monthly, so a new download will not match the recorded checksum. | `uv run python scripts/fetch_public_data.py indicators` |
| Kevin Hillstrom, MineThatData E-Mail Analytics and Data Mining Challenge (2008-03-20, 64,000 customers) | E3c | <https://blog.minethatdata.com/2008/03/minethatdata-e-mail-analytics-and-data.html>. **No licence stated by the author.** Used for research only; never redistributed, never in a commercial benchmark. | `uv run python scripts/fetch_public_data.py hillstrom --research-use-only` |

## Derived files kept in the repository

| path | what it is | derived from |
|---|---|---|
| `experiments/E3d/served/*/metrics.csv` | one row per month: trip count and sums of the fare columns (the "already served" numbers of the pipeline tasks) | NYC TLC trip files |
| `experiments/E3d/tlc_footers.json` | column names, types, row counts and null counts read from the parquet footers | NYC TLC trip files |
| `experiments/E3d/served/*.txt` | build logs of the governed pipeline (column-contract messages) | NYC TLC trip files |
| `experiments/E3a/`, `experiments/E3b/`, `experiments/E4/` question banks, answer keys, semantic models | questions written by models that had not seen the gate code; reference answers are aggregates (sums, counts, rates) | UCI Online Retail II |
| `docs/experiments/*/` | reports with aggregate tables and charts | all of the above |

**Not distributed:** the E3c request bank and answer key (`experiments/E3c/bank_v2.yaml`, `keys_v2.yaml`), because
the Hillstrom file has no licence. The key was written by hand before the census and cannot be regenerated; the
reference numbers it uses can be recomputed from the fetched file with `experiments/E3c/reference_v2.py`. The scripts
that need the bank or key (`label_v2.py`, `run_v2.py`, `review_keys.py`, `experiments/E5/coverage.py`) stop with a
message saying so. The E3c reports keep their aggregate results.

## Paths and environment variables

The experiment scripts read the raw files from these defaults; each can be overridden:

| default | override |
|---|---|
| `workspace/external/online_retail_ii/online_retail_ii.parquet` | `--src` of `experiments/E3a/build_world.py` |
| `workspace/external/nyc-tlc/raw/` (with `SHA256SUMS` one level up) | `DSH_TLC_RAW` |
| `workspace/external/tlc-indicators/raw/tlc_industry_indicators.csv` | `DSH_TLC_INDICATORS` |
| `workspace/external/hillstrom/raw/hillstrom_2008-03-20.csv` | `DSH_HILLSTROM` |
| `workspace/de_dbt_cache/` (dbt package cache for E3d) | `DSH_DE_DBT_CACHE` |

The real-agent censuses also expect two Python environments next to the repository (`../agent_env`, and
`../agent_env_dt` pinned in `experiments/env_dt/requirements.txt`), the `claude` and `codex` CLIs, `bwrap`, and API
keys (see [MODEL_POLICY.md](MODEL_POLICY.md)). Per-attempt run folders and transcripts are not published.
