# Experiment plan

Updated 2026-11-07 13:00. Goal: measure what real agents get wrong in data work and whether the harness
catches it, first on the synthetic world, then on public real data. Every experiment is
pre-registered, compares arm N (no harness) with arm H (harness) where that makes sense, repeats each
item 3 times, and takes its questions or defects from models that have not seen the check code.

its truth is built.

Rules for public data:

- Data is never committed. The repo carries download scripts with SHA-256 sums; the source, version
  (download date, Last-Modified) and any modification are recorded with each run.
- Known datasets may be in the agents' training data, which flatters them. Each real-data test adds a
  control with renamed columns and shifted dates, and where possible data published after the agents'
  training cut-off (TLC 2026-09).
- Non-commercial or unclear licences: research use only, never in a commercial benchmark.
- Only datasets without personal data (Online Retail has customer numbers, no names).
- Also measured: the time to onboard each new dataset (contracts, metric definitions, semantic layer).
  That is a product number in its own right.
