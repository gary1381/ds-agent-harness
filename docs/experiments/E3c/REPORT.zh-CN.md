预注册见 [PREREGISTRATION.md](PREREGISTRATION.md)（2026-11-07 17:07 定稿）；在任何标注表生成之前做的两处补充记在

## 结论

两个 agent（Claude Code、Codex）回答了 39 道关于 Hillstrom 邮件实验的留出题（64,000 名客户，随机分成三组：男装邮件、
女装邮件、不发邮件）。N 组独立作答；H 组必须先让实验门禁（`check_readout`）放行它的带类型声明才能交付。门禁是一组程序：
重算每个带类型的数字，检查对比、合并、子组和按结果选样。

**R1 没有定论。** H 组的静默错误更少，但配对区间包含 0：

| 留出题，每组 234 次 | N | H | H − N（按题配对） |
|---|---|---|---|
| R1 静默错误（交付了但不成立） | 27.8% [18.4, 38.5] | 22.2% [13.2, 32.1] | **−5.6 个点 [−12.8, +1.7]** |
| 门禁看得见的错误（次要） | 22.6% | 6.4% | **−16.2 个点 [−24.8, −8.5]** |
| 门禁看不见的错误（次要） | 5.1% | 15.8% | +10.7 个点 |
| R2 误拦 | 0.0% | 0.0% | |
| 连续 3 次都成立 | 55.1% | 64.1% | |
| 每个成立交付的成本 | $0.07 / 14.1 万 token | $0.07 / 14.7 万 token | |

要点：
1. **门禁在它看得见的地方有效。** 有程序检查的错误（数字算错、该分开却合并、捞子组、按结果选样、过度断言）从 22.6%
   降到 6.4%，区间不含 0。
2. **它看不见的错误变多了。** "没回答问到的每一部分"（E-read）翻了一倍，从 18 条到 38 条。在门禁从没暂缓过的 H 组回答里，
   它同样多（194 条里 31 条，16%；N 组是 8%），所以不是门禁的理由造成的。更可能的原因是：按带类型声明的流程作答，
   回答的覆盖面变窄了。
3. **没有误拦。** 276 次 H 组作答里，门禁至少暂缓过一次的有 40 次（Claude 23，Codex 17），修改后全部放行。成本上看不出
   代价：每个成立交付的花费相同，token 多约 4%。
4. **模型语义检查还不够好，不能用来暂缓**（次要结果，见下）：Haiku 和 Luna 会把 17%–23% 的正确回答标成有问题。
   E3b v2 里它只做提示。

lu09 的联合检验、ha19 的区间）；ha12 有 ±0.01 的舍入差，判为通过。标注表上看不出组别，也没有回答提到门禁。

## 语义检查离线回放（次要，DEVIATIONS 11-07 23:49）

Haiku 和 Luna 对每条最终回答各回答三个固定问题（scale：把平均效应说成典型客户的收益；nodata：数据显示不了的断言；
unanswered：漏了问到的部分），每个"是"都要附原文引用，由程序核对。规则在任何标注之前就定了：只有当某个模型在正确回答
上误标不超过 5%，并且抓住至少一半门禁看不见的错误，对最终标注和对另一家模型的标注都满足，它才能在 E3b v2 的门禁里暂缓
回答。

| 判定模型 | 对照标注 | 正确回答被误标 | 抓住看不见的错误 |
|---|---|---|---|
| Haiku | 最终 | 16.7%（69/413） | 38%（24/63） |
| Haiku | Luna 的 | 17.5%（67/382） | 33%（29/87） |
| Luna | 最终 | 22.5%（93/413） | 46%（29/63） |
| Luna | Haiku 的 | 20.4%（73/358） | 55%（27/49） |

**两个都不合格。** E3b v2 的语义检查只做提示（显示理由，从不暂缓），用 Haiku：它误标更少，而提示模式下理由仍会传给
agent。"unanswered"这个问题能抓住大约一半的 E-read，正是 H 组增多的那类错误。

## 下一步

- **E3b v2**（预测题，2026-11-08 07:06 冻结，普查进行中）保留程序门禁，加上只做提示的语义检查；它的 `harm_v2.py`
  会测门禁理由有没有把对的第一版改成错的最终版。
- **下一版门禁应该瞄准 E-read**：先由模型从请求里抽出它要求的每一部分、粒度和细分，再由程序逐项核对回答有没有覆盖
  （"语义交给模型，精确交给程序"）；带类型声明的流程也应要求覆盖每个问到的部分，而不只是数字。

## 局限

- 一个数据集、两个 agent、39 道留出题，R1 的区间较宽。
- 标注来自模型（Luna、Haiku、Claude 裁决者），κ 中等；换一个裁决者，两组的 R1 可能各变动几个点。
- Hillstrom 数据公开且年代久，agent 可能见过对它的分析；效应在题内比较。
- 看得见/看不见的划分取决于答案里的代码划分，在普查前已固定。
